# B题各问算法时间复杂度分析

## 1. 符号说明

设：

- (M)：第一问中的检测点或示向度数量；
- (P)：第二问中的粒子数量；
- (C)：第二问中的候选第二检测点数量；
- (E)：第二问中的误差采样数量；
- (K)：第二问中进入精修阶段的候选点数量；
- (U)：频道数量，当前题目中 (U=20)；
- (Q)：全局覆盖点数量，问题3中为 (Q=7)；
- (N)：在线策略的决策步数；
- (S)：PPO训练总步数；
- (W)：PPO策略网络和价值网络的参数数量；
- (G)：问题4中三角网格的顶点数量；
- (V)：定位区域边界顶点数量；
- (A_R)：定位区域面积；
- (h)：三角网格边长；
- (P_{2\text{-opt}})：2-opt路径优化的最大迭代轮数。

下面的复杂度分析针对当前代码中的实际算法流程，而不是只针对数学模型本身。

---

## 2. 第一问：有界示向误差下的交会定位

对应代码：

`B题问_代码/q1_localization/localization_region.py`

第一问的主要步骤为：

1. 将每个检测点的角度误差区间转化为两个半平面；
2. 枚举任意两个半平面的交点；
3. 判断交点是否满足全部半平面约束；
4. 对可行交点去重并构造凸包；
5. 计算定位区域直径和最小覆盖圆。

### 2.1 半平面交点枚举

每个检测点产生两个半平面，因此半平面数量为

\[
H=2M.
\]

任意两个半平面的交点数量为

\[
O(H^2)=O(M^2).
\]

代码对每个交点都调用 `_satisfies`，检查它是否满足全部 (H) 个约束，因此每个交点需要

\[
O(H)=O(M)
\]

的时间。于是该阶段复杂度为

\[
O(H^2)\times O(H)=O(H^3)=O(M^3).
\]

### 2.2 凸包计算

候选点排序和 Andrew 单调链凸包算法的复杂度为

\[
O(V\log V),
\]

其中 (V) 为去重后的候选区域顶点数。二维半平面交集形成的凸多边形顶点数通常满足 (V=O(M))，因此通常为

\[
O(M\log M).
\]

### 2.3 直径计算

代码通过枚举任意两个顶点计算多边形直径，因此复杂度为

\[
O(V^2).
\]

在 (V=O(M)) 时为

\[
O(M^2).
\]

### 2.4 最小覆盖圆计算

代码枚举两点圆和三点外接圆：

- 两点圆候选数量为 (O(V^2))；
- 三点外接圆候选数量为 (O(V^3))；
- 每个候选圆都要检查全部 (V) 个顶点。

因此严格最坏情况下为

\[
O(V^3)\times O(V)=O(V^4).
\]

当 (V=O(M)) 时为

\[
O(M^4).
\]

### 2.5 第一问总复杂度

当前实现的严格最坏时间复杂度为

\[
\boxed{O(M^4)}.
\]

在通常的四站点、六站点等小规模场景中，最小覆盖圆的快速路径通常可以直接返回，因此实际主要耗时来自半平面交点筛选，通常可近似看作

\[
\boxed{O(M^3)}.
\]

空间复杂度约为

\[
\boxed{O(M^2)}，
\]

主要用于存储半平面交点和候选点。

## 3. 第二问：鲁棒第二检测点选择

对应代码：

`B题问_代码/q2_second_detection/second_detection_point.py`

第二问的主要步骤为：

1. 根据第一次示向度生成粒子；
2. 生成第二检测点候选网格；
3. 计算每个候选点的鲁棒接收率和 FIM 几何损失；
4. 选出前 (K) 个候选点进行误差网格下的最坏定位直径精修。

### 3.1 粒子生成

设角度采样数量为 (A)，距离采样数量为 (R)，则粒子数量约为

\[
P=O(AR).
\]

生成每个粒子只需要常数次三角函数和距离计算，因此粒子生成复杂度为

\[
\boxed{O(P)}.
\]

### 3.2 候选点的鲁棒筛选

对每一个候选点，需要遍历全部 (P) 个粒子，计算：

- 是否位于对应粒子的接收半径内；
- 鲁棒接收率；
- FIM 几何损失。

单个候选点的计算复杂度为 (O(P))，共有 (C) 个候选点，因此为

\[
O(CP).
\]

对候选点按照 FIM 分数排序，需要

\[
O(C\log C).
\]

### 3.3 最坏定位直径精修

对每个进入精修的候选点，需要遍历：

- (P) 个粒子；
- (E) 个误差样本。

在第二问中只有两个检测点，因此半平面数量固定为4，每次两站点几何计算可以视为常数时间。于是精修复杂度为

\[
O(KPE).
\]

### 3.4 第二问总复杂度

综合粒子生成、候选筛选、排序和精修，第二问总复杂度为

\[
\boxed{O(P)+O(CP)+O(C\log C)+O(KPE)}.
\]

通常可简写为

\[
\boxed{O(CP+C\log C+KPE)}.
\]

如果误差样本数 (E) 和精修候选数 (K) 均为固定常数，则主要复杂度为

\[
\boxed{O(CP)}.
\]

若候选点由边长为 (s) 的规则网格生成，目标圆半径为 (R_0)，则

\[
C=O\left(\frac{R_0^2}{s^2}\right).
\]

因此候选网格边长减半时，候选点数量约增加4倍，第二问计算量也会近似增加4倍。

## 4. 第三问：多目标搜索、定位与 PPO

对应代码：

- `B题问_代码/q3_common/public/candidates.py`
- `B题问_代码/q3_common/route_b/active_policy.py`
- `B题问_代码/q3_common/route_c/core.py`
- `B题问_代码/q3_common/route_c/features.py`

第三问需要区分在线策略执行和 PPO 训练两个过程。

### 4.1 一次候选动作生成

每次决策中，算法会：

1. 遍历 (Q) 个全局覆盖点；
2. 对每个覆盖点检查 (U) 个频道；
3. 对已经发现的频道进行状态筛选和排序；
4. 生成最多 (A) 个候选动作。

因此一次候选动作生成的复杂度为

\[
\boxed{O(QU+U\log U+A)}.
\]

当前代码中 (Q=7)、(U=20)、(A=12)，这些均为固定常数，因此一次候选生成在当前题目规模下近似为

\[
\boxed{O(1)}.
\]

### 4.2 一次环境动作执行

一次动作最多检测 (U) 个频道，每次检测和状态更新均为常数时间，因此基础执行复杂度为

\[
O(U).
\]

如果该动作触发重新计算定位区域，设当前频道已有 (M_i) 条示向度，则区域更新的最坏复杂度为

\[
O(M_i^4).
\]

所以单步环境执行可以写为

\[
\boxed{O(U+M_i^4)}.
\]

实际运行中并不是每一步都会重新计算完整定位区域，且 (M_i) 通常较小，因此平均复杂度会低于该最坏上界。

### 4.3 路线B在线执行

设总决策步数为 (N)，则路线B总复杂度为

\[
\boxed{
O\left(N(QU+U\log U+A+U+M_{\max}^4)\right)
}.
\]

如果暂不计入定位区域的重新计算，则为

\[
\boxed{O\left(N(QU+U\log U+A)\right)}.
\]

在当前固定的频道数、覆盖点数和候选动作数下，可以近似写为

\[
\boxed{O(N)}.
\]

### 4.4 PPO训练

PPO训练的每个时间步都需要进行环境交互；在网络更新时，还要进行前向传播和反向传播。设：

- (S)：训练总步数；
- (E_{\mathrm{ppo}})：每批样本重复训练轮数；
- (W)：网络参数数量。

则总训练复杂度可写为

\[
\boxed{
O\left(
S(QU+U\log U+A+U+M_{\max}^4)
+SE_{\mathrm{ppo}}W
\right).
}
\]

只考虑神经网络优化部分时，通常写为

\[
\boxed{O(SE_{\mathrm{ppo}}W)}.
\]

当前观察向量为757维、候选动作数为12，因此 PPO 训练的主要影响因素是训练步数 (S)、网络规模 (W) 和 PPO 更新轮数，而不是候选动作生成本身。

## 5. 第四问：定向源三角网格搜索

对应代码：

- `B题问_代码/q4_directional/triangular_grid.py`
- `B题问_代码/q4_directional/local_policy.py`
- `B题问_代码/q4_directional/controller.py`

第四问包括：三角网格生成、路线优化、全局扫描、局部重新捕获和光学覆盖回退。

### 5.1 三角网格生成

三角网格边长为 (h) 时，单位面积内的网格点数量与 (1/h^2) 成正比。因此覆盖面积为 (A_R) 的区域时，网格顶点数量约为

\[
G=O\left(\frac{A_R}{h^2}\right).
\]

对每个候选三角形，代码需要判断其是否与定位区域相交。若定位区域有 (V) 个边界顶点，则单个三角形的相交判断复杂度约为 (O(V))。因此网格构造和相交筛选复杂度为

\[
O\left(\frac{A_R}{h^2}V\right).
\]

之后还要对网格点进行排序，复杂度为

\[
O(G\log G).
\]

因此三角网格生成总复杂度为

\[
\boxed{
O\left(\frac{A_R}{h^2}V+G\log G\right).
}
\]

当定位区域顶点数 (V) 很小且近似固定时，可以简化为

\[
\boxed{O(G\log G)}.
\]

### 5.2 最近邻路线

`nearest_neighbor_order` 每次从剩余网格点中寻找距离当前位置最近的点。

第1次需要检查 (G) 个点，第2次需要检查 (G-1) 个点，依次类推，因此复杂度为

\[
G+(G-1)+\cdots+1=O(G^2).
\]

即

\[
\boxed{O(G^2)}.
\]

### 5.3 2-opt路线优化

每一轮 2-opt 会枚举两个路径边界位置，复杂度为

\[
O(G^2).
\]

如果最多执行 (P_{2\text{-opt}}) 轮，则总复杂度为

\[
\boxed{O(P_{2\text{-opt}}G^2)}.
\]

当前代码默认最大迭代轮数为4，因此在渐进意义下仍可写为

\[
\boxed{O(G^2)}.
\]

### 5.4 全局三角网格扫描

全局扫描需要访问 (G) 个网格点，每个点最多检测 (U) 个频道，因此扫描复杂度为

\[
\boxed{O(GU)}.
\]

当前 (U=20) 为固定常数，因此可近似写为

\[
\boxed{O(G)}.
\]

代入网格点数量可得

\[
\boxed{
O\left(\frac{A_R}{h^2}U\right).
}
\]

这说明三角网格边长减半时，扫描点数量约增加4倍。

### 5.5 局部三角网格重新捕获

设某个频道当前定位区域面积为 (A_i)，局部三角网格边长为 (h_i)，则局部网格点数量约为

\[
G_i=O\left(\frac{A_i}{h_i^2}\right).
\]

如果最多允许 (K_{\max}) 次局部尝试，则局部重新捕获的网格扫描复杂度为

\[
O\left(K_{\max}\frac{A_i}{h_i^2}\right).
\]

每次重新获得示向度后，还可能重新计算定位区域。若该频道已有 (M_i) 条示向度，则该部分最坏为 (O(M_i^4))。因此局部策略总复杂度为

\[
\boxed{
O\left(
K_{\max}\frac{A_i}{h_i^2}
+K_{\max}M_i^4
\right).
}
\]

### 5.6 光学覆盖回退

光学覆盖网格边长为 (h_o) 时，区域面积为 (A_i) 的覆盖区域需要的覆盖点数量约为

\[
G_{\mathrm{opt}}=O\left(\frac{A_i}{h_o^2}\right).
\]

因此光学回退的复杂度为

\[
\boxed{O\left(\frac{A_i}{h_o^2}\right)}.
\]

由于光学回退只对少数长期无进展的频道执行，它通常不是正常流程中的主要计算开销。

## 6. 四问复杂度汇总

| 问题或模块 | 时间复杂度 |
|---|---|
| 第一问：半平面交会定位 | 严格最坏为 (O(M^4))，常规情况下主要为 (O(M^3)) |
| 第二问：粒子生成 | (O(P)) |
| 第二问：候选点筛选 | (O(CP)) |
| 第二问：候选点排序 | (O(C\log C)) |
| 第二问：误差精修 | (O(KPE)) |
| 第二问总复杂度 | (O(CP+C\log C+KPE)) |
| 第三问：单次候选动作生成 | (O(QU+U\log U+A)) |
| 第三问：路线B在线执行 | (O(N(QU+U\log U+A+U+M_{\max}^4))) |
| 第三问：PPO训练 | (O(S(QU+U\log U+A+U+M_{\max}^4)+SE_{\mathrm{ppo}}W)) |
| 第四问：三角网格生成 | (O(A_RV/h^2+G\log G)) |
| 第四问：最近邻路线 | (O(G^2)) |
| 第四问：2-opt路线优化 | (O(P_{2\text{-opt}}G^2)) |
| 第四问：全局扫描 | (O(GU)) |
| 第四问：局部重新捕获 | (O(K_{\max}A_i/h_i^2+K_{\max}M_i^4)) |
| 第四问：光学覆盖回退 | (O(A_i/h_o^2)) |

## 7. 可直接用于论文的总结

第一问通过枚举半平面边界交点构造有界误差定位区域，严格最坏时间复杂度为 (O(M^4))，但在通常的小规模检测点场景下主要表现为 (O(M^3))。第二问对候选检测点和粒子进行双重遍历，主要复杂度为 (O(CP))，误差精修额外增加 (O(KPE))。第三问中，频道数、覆盖点数和候选动作数均为固定常数，因此路线B在线决策的总体复杂度近似为 (O(N))；PPO训练的主要复杂度为 (O(SE_{\mathrm{ppo}}W))。第四问中，三角网格点数量与区域面积和网格边长满足 (G=O(A_R/h^2))，全局扫描复杂度为 (O(GU))，但最近邻路线和2-opt优化分别需要 (O(G^2)) 和 (O(P_{2\text{-opt}}G^2)) 的计算量。因此，第四问中最需要关注的是网格边长对网格点数量的平方反比影响，以及路径优化带来的二次复杂度。
